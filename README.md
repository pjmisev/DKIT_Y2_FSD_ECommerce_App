# E-commerce Client Application

## Description

This is a client-side application for an e-commerce website, developed as part of the Full-Stack Development module in 2nd Year of BSc (Hons) Computing in Software Development at Dundalk Institute of Technology. It allows users to browse and purchase products, as well as manage orders and products through an admin panel.

## Installation

1. Clone the repository: `git clone https://github.com/pjmisev/DKIT_Y2_FSD_ECommerce_App.git`
2. Install the dependencies in both the server and the client using: `npm install`
3. Run the server using: `nodemon start`
4. Run the client using: `npm run dev`

## Usage

1. Open the application in your browser at `http://localhost:3000`.
2. Browse and search for products using the search bar and filter menu.
3. Add products to your cart by clicking the "Add to Cart" button on the product page.
4. View your cart by clicking the cart icon in the top right corner.
5. Proceed to checkout by clicking the "Checkout" button on the cart page.
6. Log in or register to view your order details at a later date. You can order as a guest too.
7. Access the admin panel by logging in with as an admin user (Access Level 2). Manage products and orders from there.
